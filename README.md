# CartPole Q-Learning Practice

Google ColabとPyTorchを用いた、強化学習（Q学習）の基礎的な実装練習用リポジトリ。
Farama Gymnasiumの `CartPole-v1` 環境において、ポールを倒さないようにバランスを取るエージェントを学習させる最小限のコードを実装。
自身での理解と自力実装を基本としつつ、Gemini 3.1 Proをチューター役として活用した。（不明点の質問や最終チェックなど）。
完璧な成果物ではなく、まだ強化学習の全てを学んでいない段階でものづくりすること自体に迷いもあったが、これまで学んだことをアウトプットできる場面が複数あり、基礎学力定着の面で意義があったと思う。

## 概要と現在の実力

深層強化学習の初歩としての実装練習であるため、最低限のオンライン学習ループのみを構築した。

### 実装できていること
* Gymnasiumを使った環境の初期化と状態（Observation）の取得
* PyTorchを用いたシンプルなQネットワーク（MLP: 入力4層 -> 隠れ128層 -> 出力2層）の構築
* $\epsilon$-greedy法に基づく探索と利用の行動選択戦略
* ベルマン方程式に基づくLoss（平均二乗誤差）の計算と誤差逆伝播（Adam最適化）

### 意図的に見送ったこと（現在の課題）
* **DQNの完全な実装:** Experience Replay（経験メモリ）やTarget Networkといった複雑な仕組みは、現時点での地震の理解度に合わせて意図的に実装を見送った。
* **破滅的忘却の発生:** Geminiによれば、上記の理由により、1ステップごとの単純なオンライン学習を行っているため、エピソードが進むと過去の成功体験を忘れてスコアが急落する「破滅的忘却」が発生する。
* **学習成立のためのハック:** Geminiの提案で、最小構成でも学習の方向性を掴ませるため、ゲームオーバー時（`terminated`）にターゲットQ値を強制的に `-1.0` にするという簡易的なペナルティ処理で代用した。

## 実行環境
* Google Colab
* Python
* Gymnasium
* PyTorch

## 学習結果
学習初期はランダムに行動しすぐにポールが倒れるが、「ランダム率」の減少に伴い、一時的に平均スコア200台〜300近くまで到達することを確認した（その後、「破滅的忘却」によりスコアは不安定になる）。
